# 更新记录

## v0.3.2 正式版

2026-09-17 指定为正式版。之后的维护更新仍沿用该版本号。

改善公开信息核验和成本判断，明确缺少关键事实时的条件性建议；分析结果优先展示结论、决定性原因和主要风险。

信息不足时逐步追问必要背景。简化安装与使用说明，将可安装的技能和公开文档分开，并加强安装更新时的覆盖保护与失败恢复。

这些变化不代表 AI 分析没有遗漏或偏差，使用范围见[版本说明](RELEASE_STATUS.md)。

改善雇主认可度信息不足时的判断，避免将“缺少证据”直接视为“两个项目等价”。
