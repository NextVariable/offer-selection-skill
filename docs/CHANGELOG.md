# 更新记录

## v1.0.0 — 2026-11-22

发布验收版本要求确认事实具有已打开、适用且支持该主张的原始来源记录。支持离线降级旧台账，解除受影响门槛的确定状态，并在快速报告显示来源和关键门槛状态。

加入离线 Decision Engine，执行全成本、现金流、分类压力测试、证据适用期与资格状态检查。原有规则继续负责研究、竞争力和增量价值判断。提供同一份结构化结果的快速与完整报告，以及单变量反事实的事实复用、重新核查和结果对照。

发布硬化补充：快速报告显示净现金区间、上限比较、余量或超出、预算口径与未量化成本行，并列出带影响级别的待核实主张；宿主契约要求先确认预算口径，CI 增加发布契约、隐私与路径扫描。详见[发布硬化审计](V1_RELEASE_AUDIT.md)。

独立审核修复了无金额上限时快速报告遗漏费用、不完整账本给出过于确定的预算子状态，以及反事实与原始输入共享嵌套数据的问题。拟支持范围与验收记录见[兼容性](COMPATIBILITY.md)。

## v0.4.0 候选版

在既有决策流程中补充学术适配、资金支付节点与压力测试、可达的城市产业机会，以及有明确支付意愿的声望和体验溢价。职业收益接近时，实质成本差异可以改变接受建议。

市场证据不完整时，可给出说明依据与翻转条件的方向性建议。未核实的决定性资格仍保留条件分支，并限制评分精度。

## v0.3.2 正式版

2026-09-17 指定为正式版。之后的维护更新仍沿用该版本号。

改善公开信息核验和成本判断，明确缺少关键事实时的条件性建议；分析结果优先展示结论、决定性原因和主要风险。

信息不足时逐步追问必要背景。简化安装与使用说明，将可安装的技能和公开文档分开，并加强安装更新时的覆盖保护与失败恢复。

这些变化不代表 AI 分析没有遗漏或偏差，使用范围见[版本说明](RELEASE_STATUS.md)。

## v0.3.1 — 2026-09-07

改善雇主认可度信息不足时的判断，避免将“缺少证据”直接视为“两个项目等价”。

整理统一决策流程，区分回国私企、国央企或体制内、当地就业与学术深造四类目标。
