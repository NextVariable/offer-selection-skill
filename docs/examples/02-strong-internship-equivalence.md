# Example 02 — Strong internships, same offers

## Setup

- Undergraduate: ordinary (双非) institution, business major.
- Offers: **School A** and **School B** — the same pair as Example 01
  (same-tier brand, different internship access).
- Internships: **three strong, relevant internships** with measurable output.
- Goal: return to China for private-sector product roles.
- Budget: both offers fit.

## Expected behavior

The internship gap no longer exists, so School B's internship-repair advantage
has little marginal value: "the fourth/fifth ordinary placement has low
marginal value." The two offers move toward **Decision Equivalence**. The
engine returns the real remaining trade-offs — cost, city, experience, brand
preference — to the user as subjective utility, and does **not** force a
winner or invent a numeric gap. If a small directional preference remains
(e.g. School A is meaningfully cheaper), it is stated as a weak preference,
not a tier difference.

## What this is NOT

- Not "both are always equal." If independent evidence supports a material
  difference (e.g. one program is materially cheaper with the same target-market
  outcome), the engine states it honestly instead of compressing the scores.
- Not a fixed "≤ N points = equivalent" rule. Equivalence is an evidence
  judgment, never score arithmetic.

## Lesson

Opportunity value is gated by whether the user still has that gap. The engine
must not reward capital the user already owns.
