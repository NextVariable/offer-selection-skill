# Example 03 — Ordinary vs. strong undergraduate

## Setup

- Offer: **School A** — a recognized master's in a non-technical business field.
- Goal: return to China for private-sector employment.

Two student profiles are compared against the *same* offer.

### Profile A — ordinary (双非) undergraduate

The master's may be a **material credential upgrade**: it can change the
graduation profile by adding a recognized name-brand signal the student did
not have.

### Profile B — strong (top-tier) undergraduate

The same master's may add **little or nothing** to the credential the student
already holds. For pure China-return employment, a second taught master's may
even be low-ROI or unnecessary. The engine must not manufacture an "upgrade"
that has no career value, and must not demand one.

## Expected behavior

Transformation is **baseline-dependent**. The same offer scores very
differently for the two profiles. The engine judges what the offer can
*incrementally* change — the undergraduate baseline is fixed and is not a lever
the offer can move.

## What this is NOT

- Not "strong undergraduates should never do a master's." The judgment is
  about *this offer's incremental value for this goal*.
- Not a ranking arithmetic. "Top bachelor → must avoid ordinary master's" is a
  heuristic about transformation, not a hard school branch.
