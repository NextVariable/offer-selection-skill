Harness 需要宿主允许本地 Python 3.10+ 和私有 JSON 文件。若宿主只能对话、不能执行命令，仍可按 v1 文本契约运行，但研究任务状态、检查点、结构化轨迹和程序化证据复查不会执行，报告必须注明这一点。

完整流程需要可联网研究的宿主、可打开的原始网页、可写的工作目录和本地 **Python 3.10+**。执行模块仅使用 Python 标准库。允许查网页、运行本地 Python 和写入本地文件是独立的权限。若宿主无法运行 Python，仍可使用文本规则，报告应注明程序校验未执行。

Linux、macOS 和 Windows 的自动化检查覆盖程序或安装器环节。原生验收只覆盖表中列出的环境。更换宿主、模型、操作系统或权限设置后，行为可能不同。
