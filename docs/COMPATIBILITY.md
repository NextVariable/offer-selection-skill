# AI Agent 兼容性

v1.0 的正式支持范围为 **Codex CLI**。v2.0 候选版保留同一安装方式，并新增本地 Harness；v2 尚未完成原生宿主端到端验收，下表不把回退运行或离线测试算作宿主通过。验证等级按实际宿主、版本和测试范围记录。安装方法见[安装说明](INSTALLATION.md)。

| 宿主 | v1.0 验证范围 |
|---|---|
| Codex CLI | 在 macOS 上使用 0.171.0-alpha.13 完成指定原生案例，覆盖安装副本调用、原始网页研究或冻结证据回放、校验、报告，以及预算反事实。最终审核代码另行复测了默认 Quick 和预算边界。 |
| Claude Code | 兼容性部分验证。提供安装方式，早期候选已有原生使用记录。最终原生验收遇到第三方模型网关 402，指定案例为 **Not Run**。 |
| TRAE | 实验性支持。在 TRAE Agent 中完成部分移交案例的回退检查。整套最终原生流程未验收。 |
| WorkBuddy | 实验性支持。已验证技能安装和发现。完整决策流程待验证。 |
| 其他 Agent | 安装或导入选项为实验性支持。 |

## v2.0 候选版

| 范围 | 状态 |
|---|---|
| 决策引擎与 Quick/Full | 复用 v1.0.0，已通过 v1 回归 |
| Harness 单元/集成/CLI | 41 项本地测试通过；CI 配置覆盖 Linux/macOS |
| Codex CLI 原生 v2 端到端 | **Not Run** |
| Claude Code 原生 v2 端到端 | **Not Run**（v1 最终轮遇到网关 402） |
| Trae Agent 回退运行 | 只可作为回退证据，不能冒充原生宿主通过 |

Harness 需要宿主允许本地 Python 3.10+ 和私有 JSON 文件。若宿主只能对话、不能执行命令，仍可按 v1 文本契约运行，但研究任务状态、检查点、结构化轨迹和程序化证据复查不会执行，报告必须注明这一点。

完整流程需要可联网研究的宿主、可打开的原始网页、可写的工作目录和本地 **Python 3.10+**。执行模块仅使用 Python 标准库。允许查网页、运行本地 Python 和写入本地文件是独立的权限。若宿主无法运行 Python，仍可使用文本规则，报告应注明程序校验未执行。

Linux、macOS 和 Windows 的自动化检查覆盖程序或安装器环节。原生验收只覆盖表中列出的环境。更换宿主、模型、操作系统或权限设置后，行为可能不同。
