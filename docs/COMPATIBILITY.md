# AI Agent 兼容性

使用支持本地 Skill 的 AI Agent，并开启联网搜索。安装方式见[安装说明](INSTALLATION.md)。

| AI Agent | 安装方式 | 使用说明 |
|---|---|---|
| Codex | 对话安装、终端命令或本项目脚本 | 已有实际调用记录；安装后新建对话 |
| Claude Code | 对话安装、终端命令或本项目脚本 | 已有实际调用记录；安装后新建对话 |
| WorkBuddy | 对话安装、界面导入或本项目脚本 | 已确认文件安装和技能发现，完整使用流程仍待验证 |

Codex 和 Claude Code 的调用记录对应较早版本，不代表每个版本、系统或模型组合都已验证。Windows 安装脚本通过自动检查，不等于所有 Windows AI Agent 的使用流程均已验证。

对话安装需要 AI Agent 具备下载仓库和写入本地技能目录的权限；无法自动安装时，请使用手动方式。安装完成但找不到技能，可刷新技能列表或新建对话。

其他 AI Agent 的安装选项为实验性支持，尚未验证完整使用流程。
