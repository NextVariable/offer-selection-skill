# 隐私说明

本技能没有作者运营的数据后台、遥测或统计服务，不要求提供 API 密钥。你的对话由所使用的 AI Agent 处理；保存期限、训练用途和日志设置取决于该平台及你的账号配置。

## 使用时提供什么

可以提供比较 Offer 所需的院校、专业、成绩、经历、目标和预算。无需提供姓名、学号、邮箱或完整 Offer 信件；粘贴录取信息时，请先去除身份标识。

技能规则要求联网查证只使用学校、项目、岗位、地区和适用时间等必要的公开信息，不将私人奖学金、家庭财务和身份信息用于搜索。规则不能替代平台的隐私保障，敏感内容提交前请确认 AI Agent 的数据设置。

## 反馈问题时

公开 Issue 或截图请去除姓名、成绩、联系方式、信件编号和财务明细。不要上传真实 Offer 信件、成绩单、简历或财务记录；可用虚构数据说明问题。

发现敏感信息泄露或安全问题时，请按[安全说明](SECURITY.md)私下报告。

## 开源范围

GitHub 公开仓库中的文件及提交历史都可查看。本项目只发布筛选后的技能、安装工具和必要文档，内部测试对话与私人资料不随公开包发布。曾经公开的内容不会因删除或移动文件而自动从 GitHub 历史中消失。
