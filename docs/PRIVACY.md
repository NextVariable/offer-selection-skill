# 隐私说明

本技能没有作者运营的数据后台、遥测或统计服务，不要求提供 API 密钥。你的对话由所使用的 AI Agent 处理；保存期限、训练用途和日志设置取决于该平台及你的账号配置。

## 使用时提供什么

可以提供比较 Offer 所需的院校、专业、成绩、经历、目标和预算。无需提供姓名、学号、邮箱或完整 Offer 信件；粘贴录取信息时，请先去除身份标识。

技能规则要求联网查证只使用学校、项目、岗位、地区和适用时间等必要的公开信息，不将私人奖学金、家庭财务和身份信息用于搜索。规则不能替代平台的隐私保障，敏感内容提交前请确认 AI Agent 的数据设置。

## v2 Harness 本地状态

v2 的 Harness 只把 Case State 写到宿主指定的本地 JSON 文件，不上传到本项目。状态包含用户提供的背景、研究任务、证据主张与来源 URL/定位、检查点、反事实和执行轨迹，因此同样属于私人材料。

- 默认保留期为 7 天。到期后首次成功读取状态时，CLI 会先将案例与反事实中的个人背景清除并写回，再执行用户命令。即使命令随后失败，清除仍生效，trace 记录 `privacy_retention_expired`。
- `privacy --purge` 会立即清除原始案例和反事实中复制的个人背景；已校验的 Decision 仍可渲染，trace 记录 `privacy_purge`。
- 清除范围是 `profile` 对象及其在 scenario 中的副本。证据主张、来源 URL、决策理由和 trace 中的自由文本不会被自动改写；如果宿主把姓名、成绩或联系方式写进这些字段，它们仍会保留。请让宿主只写公开事实。
- 在支持 POSIX 权限的系统上，新写入的状态及写入期间的临时文件仅供当前用户读写（`0600`）。旧版固定名称的 `<state>.tmp` 会在下次成功读取状态时清理。进程被强制终止后若留下临时文件，请在关闭相关会话后清理。Windows 文件访问权限由目录 ACL 决定。
- 不把状态文件、原始对话或含身份标识的截图提交到公开仓库或 Issue。
- 状态文件不应长期放在共享目录或云同步目录。

## 反馈问题时

公开 Issue 或截图请去除姓名、成绩、联系方式、信件编号和财务明细。不要上传真实 Offer 信件、成绩单、简历或财务记录；可用虚构数据说明问题。

发现敏感信息泄露或安全问题时，请按[安全说明](SECURITY.md)私下报告。
