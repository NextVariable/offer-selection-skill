# 版本与使用范围

当前正式版是 [v2.0.0](https://github.com/NextVariable/offer-selection-skill/releases/tag/v2.0.0)。

**STABLE RELEASED / FEATURE FROZEN / MAINTENANCE MODE**

v2 保留 v1 的领域规则，新增可选的本地研究、证据检查、恢复与反事实执行工具。

正式支持 **Codex CLI**。既有原生运行用一个合成回国私企案例完成联网、中断恢复、逐 Offer 覆盖、条件性建议、Quick/Full 和预算反事实。发布收口时已独立复核这次运行的来源、资格和结果，并重放已有记录。Claude Code 的 v2 原生验收未运行；TRAE 的联网回退与其他宿主的安装证据分别记录。

发布审批及 CI 记录见 [PR #4](https://github.com/NextVariable/offer-selection-skill/pull/4) 和[维护者签核](RELEASE_CHECKLIST_V2.md)。
